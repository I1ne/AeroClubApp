# Мобильное приложение для управления аэроклубом

**Статус:** Учебный проект (курсовая работа)  
**Университет:** РЭУ им. Г. В. Плеханова, ВШКМиС, кафедра информатики  
**Дисциплина:** Разработка мобильных приложений  
**Автор:** Нетиевский И. С.
**Технологии:** C#, Xamarin.Forms, .NET  

## Краткое описание

Мобильное приложение автоматизирует ключевые процессы аэроклуба: запись клиентов на полёты, бронирование услуг, просмотр каталога тарифов и управление профилем. Реализовано с использованием Xamarin.Forms для обеспечения кроссплатформенности (Android, iOS).

Приложение разрабатывалось в рамках курсовой работы по дисциплине «Разработка мобильных приложений» с полным циклом проектирования:
- анализ бизнес-процессов аэроклуба,  
- моделирование в BPMN и UML,  
- создание интерфейсов и программного кода.

## Основные функции

- **Welcome Page** – стартовая страница с навигацией по разделам  
- **О нас** – информация об аэроклубе и доступных самолётах  
- **Каталог услуг** – пакеты услуг (ознакомительный полёт, ночной, экскурсионный, групповой) с подробным описанием  
- **Личный кабинет** – сохранение и редактирование личных данных (ФИО, телефон, дата рождения)  
- **Бронирование** – выбор тарифа, даты, количества пассажиров с подтверждением записи

## Как запустить

1. Клонируйте репозиторий:  
   `git clone https://github.com/I1ne/AeroClubApp.git`
2. Откройте решение в Visual Studio 2022 с установленной рабочей нагрузкой **.NET Multi-platform App UI development**.
3. Восстановите NuGet-пакеты.
4. Выберите целевую платформу (Android/iOS) и запустите проект.
